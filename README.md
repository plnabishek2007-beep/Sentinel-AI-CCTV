# 🛡 Sentinel AI CCTV System

## 🚀 Features
- Face Recognition
- Unknown Intruder Detection
- Auto-Learning Faces
- Behavior Detection (Running / Suspicious)
- Telegram Alerts (Image + Video)
- Flask API + Live Stream

## 🧠 Tech Stack
- OpenCV
- YOLOv8
- face_recognition
- Flask

## ▶️ Run

pip install -r requirements.txt
python main.py
